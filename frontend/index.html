如何把你自己的电脑变成大家都能访问的网页服务器？

只需两步：第一步在你电脑上启动本地 Web 服务程序（托管这个游戏网页）；第二步开启内网穿透隧道，生成一个公网链接发给朋友。只要你电脑开着、程序没关，全世界任何人点开链接都能直接玩！

STEP 1 · 本地启动网页服务

在电脑运行服务端

把本网页保存为 index.html（或解压配套的服务端压缩包），在该文件夹打开终端/CMD，运行以下命令即可启动 8080 端口服务：

python -m http.server 8080

💡 若使用配套压缩包里的 python server.py，还能激活多人跨设备实时共用排行榜！

STEP 2 · 同 Wi-Fi 局域网访问

家里/宿舍/办公室直连

服务启动后，你自己电脑浏览器访问 http://localhost:8080 即可打开。连在同一个路由器/Wi-Fi 下的手机或朋友电脑，输入你的局域网 IP 即可秒开：

http://192.168.x.x:8080

💡 查看本机局域网 IP：Windows 运行 ipconfig，Mac/Linux 运行 ifconfig。

STEP 3 · 让外网所有人都能访问

一行命令开启内网穿透

家用宽带通常没有公网 IP。使用免费的 Cloudflare Quick Tunnel（无需注册账号）或 ngrok，一条命令就能把本地 8080 端口映射为全球可访问的 https://xxx.trycloudflare.com 网址：

cloudflared tunnel --url http://localhost:8080

💡 也可使用 ngrok http 8080，复制生成的 https 链接发给微信/QQ好友即可畅玩！

🛡️ 6 层网络安全与防作弊实时防御盾

当你的电脑对公网开放时，backend/security.py 与 backend/database.py 会自动执行以下 6 道安全关卡（点击下方按钮可模拟黑客攻击测试）：

1. 防 SQL 注入 (SQLi)
SQLite3 强制使用 ? 参数化预编译查询，杜绝拼接 SQL 删库。
2. IP 令牌桶限流 (防 CC/DDoS)
自动识别真实公网 IP，超频请求直接返回 429 Too Many Requests。
3. HMAC 战绩防篡改签名
开局签发一次性加密令牌并校验游戏时长与分数上限，拦截抓包改分。
4. XSS 清洗与目录沙箱
转义恶意 <script> 脚本、限制 4KB 请求体、锁定静态文件目录防穿越。
